# Tp_GestionDeBiblioteca_Grupo4
Se Necesita un programa para llevar la gestión de una biblioteca, el mismo deberá poder realizar acciones tales como, dar de alta un libro y dar de alta una categoría. Además deberá permitirnos modificar cualquiera de las anteriores. Asimismo deberia mostrarnos reportes sobre:
-Cantidad de Libros Alquilados
-Cantidad de Categorias
-Libro que mas se alquilo 
-Categoría mas solicitada
